# foodiexz showcase brief

Create an 18-second, silent, editable motion graphic that introduces foodiexz as a full-stack food ordering experience. The video must use verified repository capabilities only: restaurant discovery, cart and checkout validation, wallet payment support, live delivery tracking, scheduled orders, and notifications. Use the repository's light UI palette with warm orange food accents, editorial typography, strong edge anchoring, and a product-led rhythm suitable for a GitHub README.

The composition is intentionally self-contained. It does not scrape the deployed site, require credentials, or use external media assets.
